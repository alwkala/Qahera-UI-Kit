# Operational Memory: Canonical Templates Catalog (18 Tracks)

<!-- last-verified: 2026-09-12 -->

Authoritative map of the 18 production-ready template tracks in Qahera UI Kit (`templates/`). When an agent or developer needs to compose screens, it should inspect and dogfood these tracks first.

---

## 18 Template Tracks

| Track ID | Directory | Composed Patterns | Target Experience & Features |
|---|---|---|---|
| **Admin CRUD** | `templates/admin/` | `data-table-toolbar`, `filter-bar`, `pagination`, `confirmation` | Full back-office resource manager, bulk selection, export, and deletion confirmation. |
| **Authentication** | `templates/auth/` | `form-actions`, `empty-state` | Login, Registration, Forgot Password, Reset Password, and 2FA PIN verification. |
| **Box Cards** | `templates/box-cards/` | `dashboard-stat`, `form-actions` | Basic Box (elevated/outline), Advanced Box (fullscreen, collapse, dismiss), Color Boxes. |
| **Charts & Telemetry** | `templates/charts/` | `dashboard-stat`, `data-table-toolbar` | Chart.js, Morris smooth curves/donuts, Flot streaming telemetry, and Peity micro-charts. |
| **Dashboard** | `templates/dashboard/` | `dashboard-stat`, `data-table-toolbar`, `pagination` | Executive analytics, telemetry stats, active sessions, and recent transactions. |
| **Documentation** | `templates/documentation/` | `search-toolbar`, `pagination` | Technical reference layout, sticky sidebar navigation, breadcrumbs, and code blocks. |
| **E-Commerce** | `templates/ecommerce/` | `search-toolbar`, `filter-bar`, `pagination`, `luxury-product-card` | Faceted product catalog, category tabs, cart summary, and checkout flow. |
| **Education** | `templates/education/` | `dashboard-stat`, `filter-bar` | Course syllabus, video lecture player layout, quiz modules, and progress tracking. |

| **Layouts & Rails** | `templates/layouts/` | `dashboard-stat`, `search-toolbar` | Boxed Layout (1380px), Fixed Layout (Header & Sidebar), and Collapsed Mini-Sidebar Rail. |

| **Widgets & Modular** | `templates/widgets/` | `dashboard-stat`, `editorial-story` | KPI metric tiles, chart widgets, social counters, 4-day weather cards, and timeline feeds. |
