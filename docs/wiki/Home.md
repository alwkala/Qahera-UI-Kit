# Welcome to the Qahera UI Kit Wiki

**Qahera UI Kit** (قاهرة لتصميم الواجهات) is the premier, contract-governed, AI-native design system engineered for bidirectional (Arabic RTL / English LTR) digital platforms. Built by [Alwkala Studio](https://github.com/alwkala), it synthesizes:

1. **shadcn-style Source Ownership**: Developers own the code directly in their repository without runtime framework lock-in.
2. **daisyUI-style Token Utility**: 335+ semantic design tokens and 13 authentic Cairo neighborhood themes.
3. **Preline-style Multi-Stack Parity**: 100% semantic vocabulary parity across React 19 / RSC, PHP 8.x Plates, Native HTML, Web Components, and HTMX.
4. **Sovereign AI Decision Layer**: Native Model Context Protocol (MCP) server providing autonomous coding agents with machine-readable contracts and deterministic guardrails.

---

## The Core Equation

$$\mathbf{\text{Qahera UI Kit}} = \mathbf{\text{Design System}} + \mathbf{\text{Registry}} + \mathbf{\text{AI Decision Layer}}$$

Unlike traditional component libraries that merely dump CSS classes on screen, Qahera is structured as an authoritative compiler pipeline:
* **Contracts (`contracts/`)**: Define the canonical vocabulary, props, and accessibility roles.
* **Recipes (`recipes/`)**: Map tokens to scoped atomic CSS.
* **Tokens (`tokens/`)**: W3C Design Tokens Community Group (DTCG) specification with day/night light/dark modes.
* **Behaviors (`behavior/`)**: Zero-dependency Alpine.js hydration modules.
* **Multi-Target Renderers (`renderers/`)**: Deterministic code generators for 5 production environments.
