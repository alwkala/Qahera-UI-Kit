1. نمط الأسئلة الشائعة المتصل (Bordered Accordion)

تمدد أحادي مع إغلاق تلقائي للأسئلة الأخرى (Single-Expand Mode)

منظومة قاهرة (Qahera UI Kit) هي نظام تصميم متكامل للشرق الأوسط والعالم العربي، مبني على عقود برمجية محكمة (YAML Contracts) وبصمة عميل صفرية (0kb Client RSC) وتماثل كامل للاتجاهين LTR و RTL بالاعتماد الكلي على خصائص CSS المنطقية.
الاتجاه ليس قالباً ثانوياً بل بنية تحتية أصيلة عبر خصائص margin-inline-start و padding-inline-end و border-block-end، مما يضمن التماثل الدقيق بدون الحاجة لكتابة قواعد CSS مضاعفة.
الخطوط الأساسية الحصرية هي خط Alexandria للعناوين والشعار والهوية، وخط Cairo للنصوص والواجهة وعناصر التحكم، مع حظر خط Amiri تماماً لملاءمته للكتب وليس واجهات المستخدم العصرية.

2. نمط البطاقات المنفصلة متعددة الفتح (Separate Cards Accordion)

بطاقات مستقلة تدعم فتح أكثر من قسم معاً (Multi-Expand: true) مع أيقونات تمييزية

يتم تطبيق سياسات Row-Level Security الصارمة على مستوى قاعدة البيانات لضمان عدم تسريب البيانات بين المستأجرين في المنصات متعددة الأطراف (Multi-Tenant).
بفضل بنية الأنماط المجزأة وعدم الاعتماد على مكتبات ثقيلة، تحقق كافة المكونات درجات 100/100 في مؤشرات أداء Core Web Vitals مع بصمة مضغوطة للغاية.

3. نمط الفخامة الذهبي (Luxury Accordion)

خلفية داكنة مع حدود وتفاصيل ذهبية مميزة مستوحاة من طراز الوكالة الفاخر

تتيح واجهة النمط الذهبي تجارب مستخدم حصرية للعلامات التجارية الراقية ومواقع الإطلاق الفاخرة، مع لمسات التدرجات الذهبية والتباين الداكن العميق.
تتكامل منظومة قاهرة بسلاسة مع حزمة Alex Admin Kit للوحات التحكم الإدارية و Qena UI Kit لتطبيقات الهواتف المتقدمة.
