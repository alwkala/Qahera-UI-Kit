02 • THE REAL PROBLEM

الذكاء الاصطناعي يختصر وقت البرمجة، لكنه يضاعف عشوائية التصميم

توليد الأزرار والبطاقات بالـ Prompt أمر سهل للغاية. لكن المعضلة الهندسية الحقيقية: كيف تمنع الوكيل البرمجي من إعادة اختراع نظامك البصري عند كل محادثة؟

التوليد الإحصائي العشوائي (Raw AI Prompts)

Design Entropy

يعيد الوكيل اختراع فئات الألوان والمسافات في كل طلب، ويكسر اتجاه القراءة بخصائص فيزيائية محظورة (ml-4)، ويقحم رموز الإيموجي العشوائية كبديل رخيص للأيقونات المؤسسية.

<!-- كود هش وغير متسق ينهار في الـ RTL -->
<button class="bg-blue-600 ml-4 py-2 px-4 rounded text-white">
  <span>حذف السجل</span>
  <span>🗑️</span> <!-- إيموجي عشوائي محظور -->
</button>

لغة قاهرة المعمارية المنضبطة (Canonical Grammar)

Constrained Grammar

يعمل الوكيل داخل معجم موثق. المكون محكوم بعقد YAML صريح، وبخصائص منطقية أصلية، وأيقونة SVG معيارية من السجل الرسمي الـ 41 دون أي تشوه دلالي عبر React أو PHP أو HTML.

<!-- كود موثق بالعقد ومحكوم بمتغيرات المنظومة -->
<button class="qhr-btn qhr-btn--danger qhr-btn--md" type="button">
  <span class="qhr-btn__label">حذف السجل</span>
  <svg class="qhr-icon qhr-icon--delete" viewBox="0 0 24 24">...</svg>
</button>
03 • ARCHITECTURAL SEPARATION

فصل الهوية الدلالية عن تقنية العرض (Semantic Parity)

الزر هو زر. ليس "React Button" أو "PHP Button" أو "Tailwind Button"؛ هذه مجرد استراتيجيات عرض. قاهرة تفصل القصد التصميمي وتترجمه دون أي انزلاق في المفردات.

LAYER 01

الإنسان (Human)

يفكر بالقصد الدلالي والغرض الوظيفي: "أريد لوحة عمليات وجداول بيانات مجمعة".

LAYER 02

الذكاء الاصطناعي (AI)

يمتلك قواعد التركيب والمعجم المقيد: Dashboard → DataTableToolbar → Table → Pagination.

LAYER 03

المتصفح (Browser)

يتلقى تنفيذاً حتمياً: كود HTML دلالي + 0kb RSC + خصائص CSS منطقية ووصولية معتمدة.
