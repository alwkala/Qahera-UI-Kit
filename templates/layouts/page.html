معمارية التخطيط المؤطر (Boxed Layout)

المواصفة 01

يحدد التخطيط المؤطر أقصى عرض للشاشة عند 1380px مع توسيط الحاوية في المنتصف، مع إبراز خلفية خارجية مغايرة وظلال جانبية ناعمة. يمنع تشتت العين على الشاشات فائقة الاتساع (Ultrawide).

/* تطبيق التخطيط المؤطر في قاهرة */ .ly-app-shell.is-boxed { max-width: var(--ly-boxed-width, 1380px); margin-inline: auto; box-shadow: var(--ly-boxed-shadow); border-inline: 1px solid var(--ly-border); }

التثبيت المستقل والشريط المطوي (Fixed & Rail)

المواصفة 02

يثبت الرأس والشريط الجانبي بمواضع sticky أو fixed، مما يمنح المحتوى حاوية تمرير مستقلة. في وضع الطي (Collapsed)، يتقلص العرض إلى 74px مع تفعيل تلميحات الـ Tooltips التلقائية.

/* تطبيق التثبيت والشريط المطوي */ .ly-sidebar.is-collapsed { width: var(--ly-sidebar-mini, 74px); } .ly-sidebar.is-fixed { position: sticky; height: calc(100vh - var(--ly-header-height)); overflow-y: auto; }
